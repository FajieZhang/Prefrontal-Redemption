# 仿短视频入口抗成瘾戒断工具 (Web / PWA 原型)

基于认知神经科学与行为干预机制的极简数字健康工具。

本项目基于目录下的研究报告《基于行为干预机制与高可靠离线语料库构建的抗数字成瘾系统设计与名言核验架构》开发。它通过将自身伪装为常用短视频应用（如 **哔哩哔哩**）的桌面入口，利用用户在无聊或焦虑时下意识点击屏幕的肌肉记忆，在启动瞬间植入 **神经认知微摩擦（Micro-friction）** 与 **严谨考证的经典哲学名言**，帮助用户唤醒前额叶皮层的反思能力，夺回注意力自主权。

---

## 🌟 核心机制与特色

1. **桌面视觉伪装（替代习惯回路）**：
   - 配置了逼真的哔哩哔哩（小电视粉色）应用图标与名称，同时支持在设置中切换为抖音、小红书等预设。
   - 用户只需将其“添加到主屏幕”，并将原本的短视频 App 移入深层文件夹即可生效。
2. **三阶段神经微交互阻断（Micro-friction）**：
   - **第 1 阶段（0~3秒）感官着陆与深呼吸**：同心动态呼吸光环、正念磬音（Web Audio 合成）、微震动与触摸锁定，强行打断指尖滑动惯性。
   - **第 2 阶段（3~8秒）严谨典籍名言与苏格拉底反思**：呈现经过学术级考证的真实名言（涵盖儒释道、古罗马斯多葛派、现代存在主义），配以启发式提问，降低说教感与心理抗拒。
   - **第 3 阶段（8秒后）尊重自主权的双向选择**：
     - **主按钮（高亮）**：“放下手机，回归现实” —— 触发战胜诱惑庆祝动效，记录专注天数与战报。
     - **次按钮（幽灵灰）**：“我确实需要使用” —— 尊重用户自决权，深层链接前往真实应用。
3. **100% 纯静态与完全离线运行**：
   - 内置 Service Worker 与紧凑型离线语料库，即便在断网或飞行模式下也能毫秒级秒开，零网络依赖，零隐私上传。

## 🚀 本地运行与快速预览

本项目为纯静态前端，无需编译安装任何依赖：

### 方式 1：Python 本地服务器
在当前文件夹打开终端，运行：
```bash
python -m http.server 8080
```
然后在浏览器访问：[http://localhost:8080](http://localhost:8080)

### 方式 2：Node.js 本地服务器
```bash
npx serve .
```

## 📱 手机端使用：如何添加到桌面

### iPhone (iOS Safari)
1. 在 **Safari 浏览器** 中打开本项目的在线网址。
2. 点击屏幕底部中央的 **“分享”按钮（带向上箭头的方框）**。
3. 在弹出菜单中向下滑动，找到并点击 **“添加到主屏幕” (Add to Home Screen)**。
4. 确认应用名称为 **“哔哩哔哩”**，点击右上角 **“添加”**。
5. **关键一步**：将您手机上原来的 B 站 App 移入不常用的文件夹，将这个图标放到平时随手最容易点到的位置！

### Android (安卓手机)
1. 使用 Chrome、Edge 或系统自带浏览器打开网页。
2. 点击右上角或底部的 **菜单按钮 (···)**。
3. 点击 **“添加到主屏幕”** 或 **“安装应用”**。
4. 桌面即可生成立即可用的应用图标。

## 🌐 部署到 GitHub Pages 指南

你可以免费且永久地将此应用部署在 GitHub Pages 上：

1. **新建 GitHub 仓库**：
   - 登录 [GitHub](https://github.com/)，点击右上角 `+` -> **New repository**。
   - 仓库名称可自定义（例如 `zen-habit-breaker`），设为 **Public**。
2. **推送代码**：
   在本项目文件夹终端执行：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit for habit breaker pwa"
   git branch -M main
   git remote add origin https://github.com/你的用户名/你的仓库名.git
   git push -u origin main
   ```
3. **开启 GitHub Pages**：
   - 进入该 GitHub 仓库的 **Settings** -> 侧边栏 **Pages**。
   - 在 **Build and deployment** 下的 **Source** 选择 `Deploy from a branch`。
   - Branch 选择 `main`，文件夹保持 `/ (root)`，点击 **Save**。
   - 等待约 1~2 分钟，页面上方会显示部署完成的在线链接，例如：`https://你的用户名.github.io/你的仓库名/`。
4. 用手机浏览器打开该链接，按照上面的指南添加到桌面即可！

## 📚 语料库说明与拓展

所有名言均位于 `quotes.js` 中，遵循报告提出的学术级三级核验标准，包含：
- `content`：原文准确表述
- `author`：规范真实作者（已剔除网络伪托）
- `source_work`：明确的第一手篇章卷册（如《论语·子罕篇》《沉思录》卷十二）
- `category`：五大认知主题之一（`self_discipline`、`memento_mori`、`eudaimonia`、`mindfulness`、`action_bias`）
- `reflection_prompt`：专属的苏格拉底式自省提问

如需添加更多名言，只需在 `quotes.js` 的 `QUOTES_DATABASE` 数组中添加新的对象即可。
